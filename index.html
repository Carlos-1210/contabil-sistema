Armazenamento de dados
Conectado a: —
Dentro do Claude, os dados são salvos automaticamente — nada a configurar. Para hospedar este sistema em outro site (fora do Claude), conecte um banco de dados gratuito no Supabase:
  1. Crie uma conta gratuita em supabase.com e um novo projeto
  2. No SQL Editor do Supabase, rode o script de configuração (peça ao Claude se precisar dele de novo — já cria a tabela, ativa a segurança por login e o tempo real, tudo de uma vez)
  3. Em Project Settings → API Keys, copie a "Project URL" e a chave anon public (ou Publishable key, se for esse o nome no seu projeto — são equivalentes)
  4. Abra o arquivo sistema-contabil.html em um editor de texto e cole os dois valores nas constantes SUPABASE_URL e SUPABASE_ANON_KEY, no topo do <script>
  5. Em Authentication → Users → Add user, cadastre um e-mail e senha para cada pessoa da equipe (marque "Auto Confirm User" para liberar o acesso na hora)
  6. Salve e hospede o arquivo em qualquer site gratuito (Netlify, GitHub Pages, Cloudflare Pages...)
🔒 Com login ativado, só quem tiver e-mail e senha cadastrados pelo administrador consegue ver ou alterar os dados — mesmo que alguém encontre o link do site.
Continuidade dos dados
No plano gratuito do Supabase, o projeto entra em "pausa" automática após 7 dias sem nenhum acesso — isso não apaga os dados, apenas hiberna o banco até alguém clicar em "Restore" no painel do Supabase. Usar o sistema durante a semana normalmente já evita isso. Mesmo assim, faça cópias de segurança regulares (ao lado) como proteção extra — o plano gratuito não guarda backups automáticos.
Equipe e permissões
Quem faz login vira automaticamente "Colaborador" (acesso operacional, sem excluir registros nem ver esta tela). A primeira pessoa a logar após esta atualização vira Administradora automaticamente. Só administradores podem promover ou rebaixar outras pessoas aqui.
⚠️ Esta é uma restrição de interface (esconde e desabilita ações para colaboradores). Ela não substitui, por si só, uma política de segurança de banco de dados por campo — para esse nível de proteção, todo o acesso à tabela já exige login (ver "Login com e-mail e senha" acima).

Atualização do sistema
Versão atual: 1.1.0
Este sistema roda como um único arquivo, sem instalação. Para atualizar, basta substituir este arquivo por uma versão mais nova enviada pelo desenvolvedor — os dados cadastrados não se perdem, pois ficam guardados separadamente, na nuvem vinculada a este sistema.
Cópia de segurança
Baixe um arquivo com todos os clientes, coletas, serviços e pagamentos cadastrados até agora. Guarde esse arquivo em um local seguro — ele pode ser usado para restaurar os dados depois.
—
Backup no Google Drive
Por segurança, este sistema não tem permissão para acessar sua conta do Google automaticamente — isso exigiria uma configuração à parte (um projeto no Google Cloud autorizado pela sua conta), que não é algo que possa ser ativado aqui dentro com um simples botão.

Mas o botão abaixo facilita o processo manual: ele baixa a cópia de segurança e já abre o Google Drive em outra aba, para você simplesmente arrastar o arquivo baixado para dentro de uma pasta.
Restauração
Restaure os dados a partir de um arquivo de cópia de segurança gerado anteriormente. Isso substitui todos os dados atuais do sistema.
